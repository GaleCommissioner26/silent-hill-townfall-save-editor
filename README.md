# Silent Hill: Townfall Save Editor

A save file editor for **Silent Hill: Townfall** (Screen Burn / Konami / Annapurna Interactive, 2026) — edit progress, unlock endings, and manage save data on PC.

## Features

- Edit chapter/story progress
- Unlock or set ending-related flags (including secret endings)
- CRTV / puzzle progress editing
- Safe editing with automatic backup of the original save before any write
- Works with Steam and Epic Games save locations

## Download

Grab the latest release from the [Releases](../../releases) page:

**`SilentHillTownfall-SaveEditor-v1.0.0.zip`**

Unzip and run `SilentHillTownfallSaveEditor.exe`. No installation required.

## Usage

1. Close Silent Hill: Townfall before editing your save.
2. Launch `SilentHillTownfallSaveEditor.exe`.
3. Select your save file (or let the tool auto-detect it).
4. Make your edits.
5. Save — a backup of your original file is created automatically in the same folder.

## ⚠️ Disclaimer

This is an unofficial, fan-made tool with no affiliation to Konami, Annapurna Interactive, or Screen Burn. Editing save files is done at your own risk. Always keep a backup. May break with future game updates as the save format changes.
